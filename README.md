# Matuszakowie

This is a website dedicated to my late grandparents.

It is also a project that helps me maintain my new skills and also learn more about web development.

In this GitHub project I use HTML, Sass, JavaScript and Jekyll. I use Docker for local development and to run Jekyll without installing Ruby directly on my computer.

# Local development

The Jekyll site is run through Docker. To start the local development server, use:

docker compose up

The website can then be viewed locally at:

http://localhost:4000

The SCSS is compiled with Live Sass Compiler in VS Code.
